Pratonton Penuh Muat Turun PDF Lengkap

Cara Menggabungkan Halaman dengan Canva Anda:

1. Muat Turun PDF A4 Tekan butang PDF Canva di atas. Fail PDF dijana mengikut format A4 Portrait sebenar (210mm × 297mm).
2. Import ke Canva Di Canva, klik Create a Design → Import File dan muat naik PDF tersebut.
3. Gabungkan Cover Sendiri Selitkan Cover Hadapan, Kata Aluan, Penghargaan, dan Cover Belakang yang anda buat di Canva pada bahagian depan dan belakang kandungan ini.
