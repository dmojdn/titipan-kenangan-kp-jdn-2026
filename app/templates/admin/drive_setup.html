Panduan Langkah-demi-Langkah Menyediakan OAuth Client ID di Google Cloud Console

Ikuti 5 langkah mudah ini untuk membolehkan integrasi OAuth 2.0 berfungsi tanpa mendedahkan kata laluan Google:

1

Buka Google Cloud Console & Cipta Projek

Layari https://console.cloud.google.com/ menggunakan akaun dmojdn@gmail.com (atau akaun pentadbir). Klik menu projek di bahagian atas dan klik "New Project". Namakan projek contohnya: Titipan-Kenangan-JDN.

2

Dayakan Google Drive API

Pergi ke APIs & Services > Library. Cari perkataan "Google Drive API", klik padanya, dan tekan butang "ENABLE" (Dayakan).

3

Konfigurasi OAuth Consent Screen

Pergi ke APIs & Services > OAuth consent screen:
  • Pilih External → Klik Create.
  • Nama Aplikasi: Titipan Kenangan KP JDN
  • User support email & Developer contact: dmojdn@gmail.com
  • Pada bahagian Test Users: Masukkan dmojdn@gmail.com sebagai penguji yang dibenarkan.
4

Cipta OAuth Client ID

Pergi ke APIs & Services > Credentials > Create Credentials > OAuth client ID:
  • Application type: Web application
  • Name: Web Client Titipan Kenangan
  • Authorized redirect URIs (Sangat Penting): Tambah URI ini:
    {{ redirect_uri }}
5

Salin Kunci ke Fail .env Projek

Buka fail .env di direktori akar projek anda, dan masukkan nilai yang diperoleh: 
GOOGLE_CLIENT_ID=xxxxxxxxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxxxxxxxxxxx
GOOGLE_REDIRECT_URI={{ redirect_uri }}
GOOGLE_DRIVE_ROOT_FOLDER_ID={{ root_folder_id }}
Selepas menyimpan fail .env, klik butang "Sambungkan Google Drive (OAuth 2.0)" di bahagian atas untuk melengkapkan pengesahan!
